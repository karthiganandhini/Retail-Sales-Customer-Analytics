# Retail Sales & Customer Analytics Using SQL

## Project Overview
This project analyzes retail sales and customer purchasing behavior using MySQL to identify revenue trends, top-performing products, and customer patterns.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- `customers` — customer details
- `products` — product information and prices
- `orders` — order dates and statuses
- `order_items` — order products, quantities, and prices

## SQL Concepts Used
- JOINs
- Aggregate functions
- GROUP BY and HAVING
- Common Table Expressions (CTEs)
- CASE statements
- Window functions: RANK(), PARTITION BY, and LAG()

## Key Findings
- Delivered revenue: ₹77,000
- Delivered orders: 7
- Units sold: 46
- Average order value: ₹11,000
- Highest-revenue product: Laptop
- Highest-revenue month: March 2026

## Business Objective
To identify sales trends, understand customer purchasing behavior, and support data-driven business decisions.
